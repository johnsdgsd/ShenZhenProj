# 一、算法服务接口：检定计划排程接口
## 1.1 接口基础信息
|项目|内容|
| ---- | ---- |
|场景|计量平台推送业务参数至算法服务，算法返回排程结果|
|客户端|计量生产调度平台|
|服务端|算法服务|
|调用链路|计量生产调度平台 → 算法服务|
|接口方法|detectPlanScheduling|
|接口路径|/restful/busiInterface/ipsService/detectPlanScheduling|
|集成方式|RESTful|
|报文格式|JSON|
|请求方式|POST|

## 1.2 请求入参总览
顶层入参为多组集合对象，全部必填：
1. `deviceParaList`：流水线检定仓参数集合
2. `dmdPlanDetList`：需求明细信息集合
3. `arriveBatchList`：到货批次信息集合
4. `detectSchList`：检定方案信息集合
5. `qualifiedStockList`：合格品库存信息集合
6. `unqualifiedStockList`：非合格品库存信息集合
7. `scheduleTimeList`：排程时间配置集合
8. `scheduleConfigList`：流水线调度配置集合
9. `nonDmdAimEquipCodeCfgList`：非需求设备目标设备类型码分配配置集合

### 1.2.1 deviceParaList 流水线检定仓参数
|参数名|字段类型|必填|说明|
| ---- | ---- | ---- | ---- |
|sysNo|VARCHAR2(32)|是|线体编号|
|sysName|VARCHAR2(128)|是|线体名称|
|deviceType|VARCHAR2(8)|是|检定仓类型（参照字典VW_DEVICE_TYPE）|
|deviceNo|VARCHAR2(32)|是|检定仓编号|
|deviceName|VARCHAR2(128)|是|检定仓名称|
|detectEquipType|VARCHAR2(8)|是|所检设备表类型（字典VW_DETECT_EQUIP_TYPE）|
|posNum|NUMBER(4)|是|表位数|

|equipCode|VARCHAR2(32)|是|设备类型码|
|equipDesc|VARCHAR2(512)|是|设备描述|
|pEquipCode|VARCHAR2(32)|否|设备类型码大码|
|sumQty|NUMBER(8)|是|汇总平衡后数量|
