# 算法服务提供接口
## 1、检定计划排程接口
|项目|内容|
| ---- | ---- |
|场景描述|计量生产调度平台将算法输入所需参数，同步给算法服务，算法服务输出计量生产调度平台所需参数|
|服务端|算法服务|
|客户端|计量生产调度平台|
|调用链路|计量生产调度平台->算法服务|
|接口函数|detectPlanScheduling|
|接口路径|/restful/busiInterface/ipsService/detectPlanScheduling|
|集成方式|restful|
|报文类型|JSON|
|请求方式|POST|
|备注|无|
