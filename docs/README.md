# docs 文件索引

按时间顺序整理。目录分 5 类：`算法脚本/`（原始算法源文件，**勿修改**）、`报文/`（真实请求报文）、`样例/`（输入/输出样例 Excel）、`接口文档/`（接口契约与差异说明）。

```
docs/
├── README.md                  # 本索引
├── 算法脚本/检定排程/          # 检定排程算法 8.03 / 8.06 / 8.07 / 8.11 / 8.16 / 8.17 / 8.25 / 8.28 / 8.28最新1（按时间演进）
├── 算法脚本/到货排程/          # 到货排程算法 8.13 / 8.14
├── 报文/                       # 智能排程报文（0807 / 0812 / V0.0.1 旧报文）
├── 样例/                       # 输入（检定仓情况）/ 输出（检定排程计划）样例 Excel
├── 接口文档/                   # 接口说明 / 接口说明v2.0 / 报文差异清单 / Word 版
└── 导出数据/                   # 自包含交付物：数据问题汇总 + 0812 数据导出 + 码值映射 + 源报文副本 + 独立导出脚本
```
